# RAG 分块策略优化：基于医学教材的实验对比报告

## 摘要

本文针对医学教材知识整合场景，对比了不同 RAG 分块策略对检索命中率的影响。通过在 6 本医学教材上构建评测集，实验对比了 300字、600字、800字三种 chunk size 的检索效果，并验证了混合检索（向量+BM25+RRF）相比纯向量检索的提升。结果表明，600字 chunk size + 混合检索方案在医学教材场景下取得最优的命中率-效率平衡。

## 1. 问题分析

医学教材的 RAG 检索面临独特挑战：
- **术语密集**：医学概念定义精确，一个关键词的差异可能改变含义
- **跨教材表述差异**：同一概念在不同教材中可能用不同术语描述
- **上下文完整性**：医学知识点的定义往往需要完整的段落上下文

现有方案的瓶颈：
- 纯向量检索：语义匹配好，但精确术语匹配差
- 纯 BM25 检索：关键词匹配好，但语义理解差
- 固定 chunk size：无法适应不同长度的知识点定义

## 2. 方案设计

### 2.1 分块策略

采用滑动窗口分块，参数化 chunk_size 和 overlap：

| 策略 | chunk_size | overlap | 理由 |
|------|-----------|---------|------|
| 小块 | 300字 | 50字 | 精度高，但上下文不足 |
| 中块 | 600字 | 100字 | 平衡精度和上下文 |
| 大块 | 800字 | 150字 | 上下文足，但精度下降 |

### 2.2 检索策略

| 策略 | 方法 | 说明 |
|------|------|------|
| 纯向量 | BGE-small-zh Top-10 | 语义检索 |
| 混合检索 | 向量 Top-10 + BM25 Top-10 → RRF(k=60) → Top-5 | 兼顾语义和关键词 |

### 2.3 评测指标

- **命中率@5**：Top-5 结果中包含正确来源的比例
- **平均响应时间**：从查询到返回结果的耗时
- **Token 消耗**：每次查询的 LLM token 使用量

## 3. 实验与结果

### 3.1 评测集

基于 6 本医学教材自动生成评测题：
- 教材：局部解剖学、生理学、医学微生物学、病理学、传染病学、病理生理学
- 题目数量：20 道（覆盖事实性、比较性、跨教材三种类型）
- 每题标注：预期答案、来源教材、来源章节

### 3.2 实验结果

| 分块策略 | 检索方式 | 命中率@5 | 平均响应时间 | Token/查询 |
|----------|----------|----------|-------------|-----------|
| 300字 | 纯向量 | 65% | 1.2s | 800 |
| 300字 | 混合检索 | 75% | 1.5s | 850 |
| 600字 | 纯向量 | 70% | 1.3s | 1200 |
| 600字 | 混合检索 | **85%** | 1.6s | 1300 |
| 800字 | 纯向量 | 68% | 1.4s | 1600 |
| 800字 | 混合检索 | 80% | 1.8s | 1700 |

### 3.3 关键发现

1. **600字 chunk size 最优**：在命中率和效率之间取得最佳平衡
2. **混合检索提升显著**：相比纯向量，命中率提升 10-15 个百分点
3. **800字反而下降**：chunk 过大导致检索精度下降，无关内容稀释了相关性
4. **300字上下文不足**：医学定义往往跨越 300 字，导致关键信息被截断

## 4. 结论

在医学教材 RAG 场景下，推荐配置：
- **Chunk size**: 600字
- **Overlap**: 100字
- **检索**: 混合检索（向量 + BM25 + RRF k=60）
- **Embedding**: BGE-small-zh-v1.5（中文优化，本地运行）
- **Top-K**: 5

该方案在 20 道评测题上达到 85% 的命中率@5，平均响应时间 1.6 秒。

## 5. 局限性与未来方向

- 评测集规模较小（20 道），需要扩充到 50+ 道以提高统计显著性
- 未测试 Rerank 二次排序的效果（预计可再提升 5-10%）
- 未对比不同 Embedding 模型（如 BGE-large-zh vs BGE-small-zh）
