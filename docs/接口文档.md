# API 接口文档

## 基础信息
- Base URL: `http://localhost:8100`
- Content-Type: `application/json`
- 所有接口均支持 CORS

---

## 文件管理

### POST /api/upload
上传教材文件并自动解析。

**请求**: `multipart/form-data`
- `file`: 文件（支持 PDF/MD/TXT/DOCX）

**响应**: Textbook 对象
```json
{
  "id": "tb_xxx",
  "filename": "生理学.pdf",
  "title": "生理学",
  "format": "pdf",
  "total_pages": 520,
  "total_chars": 385000,
  "chapters": [...],
  "upload_time": "2026-05-10T10:00:00",
  "parse_status": "completed"
}
```

### GET /api/textbooks
获取已上传教材列表。

### GET /api/textbooks/{textbook_id}/chapters
获取指定教材的章节详情。

### DELETE /api/textbooks/{textbook_id}
删除教材及其关联数据。

## 知识图谱

### POST /api/kg/build/{textbook_id}
为指定教材构建知识图谱（调用 LLM 逐章节提取知识点和关系）。

### GET /api/kg/{textbook_id}
获取单本教材的图谱数据。
```json
{
  "nodes": [{"id": "node_001", "name": "动作电位", "definition": "...", "category": "核心概念", "frequency": 1}],
  "edges": [{"source": "node_001", "target": "node_002", "relation_type": "prerequisite", "description": "..."}]
}
```

### GET /api/kg/all
获取所有教材的合并图谱。

## 跨教材整合

### POST /api/integrate
执行跨教材整合（语义对齐 + 整合决策 + 压缩）。

### GET /api/integrate/decisions
获取所有整合决策列表。

### POST /api/integrate/override
用户手动覆盖整合决策。
```json
{
  "decision_id": "merge_001",
  "action": "keep",
  "reason": "教师认为该知识点不应合并"
}
```

### GET /api/integrate/stats
获取压缩比统计。
```json
{
  "original_chars": 1200000,
  "compressed_chars": 350000,
  "compression_ratio": 0.29,
  "merge_count": 120,
  "keep_count": 200,
  "remove_count": 80
}
```

## RAG 问答

### POST /api/rag/index
为所有已上传教材建立向量索引。

### POST /api/rag/query
提问并获取带引用的回答。
```json
// 请求
{"question": "什么是炎症？"}

// 响应
{
  "answer": "炎症是机体对致炎因子的损伤所发生的防御性反应...",
  "citations": [
    {
      "textbook": "病理学",
      "chapter": "第四章 炎症",
      "page": 78,
      "relevance_score": 0.92,
      "source_chunks": ["炎症(inflammation)是具有血管系统的活体组织..."]
    }
  ]
}
```

### GET /api/rag/status
获取索引状态。
```json
{
  "indexed_textbooks": 7,
  "total_chunks": 2450,
  "status": "ready"
}
```

## 多轮对话

### POST /api/dialogue/chat
发送对话消息。
```json
// 请求
{"message": "为什么把《生理学》里的炎症和《病理学》里的炎症反应合并了？"}

// 响应
{
  "response": "这两处描述本质上是同一概念...",
  "conversation_id": "conv_xxx"
}
```

### GET /api/dialogue/history
获取对话历史。
